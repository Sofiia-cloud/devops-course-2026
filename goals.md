# Мои цели на семестр

## Цель 1: Освоить Docker и контейнеризацию

Научиться упаковывать приложения в Docker-образы, писать Dockerfile
и docker-compose.yml, запускать многоконтейнерные приложения локально.

## Цель 2: Настроить CI/CD на GitHub Actions

Разобраться, как автоматически запускать тесты и деплой при пуше в репозиторий.

## Цель 3: Уверенно работать с Linux и Bash

Освоить базовые команды навигации, работы с файлами, правами доступа,
процессами и написание простых bash-скриптов для автоматизации рутины.

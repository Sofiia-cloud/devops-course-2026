# Git в VS Code vs терминал

## 3 удобные вещи в VS Code

1. **Панель Source Control** — все изменения видны списком, можно
   закоммитить и запушить в пару кликов без ввода команд.

2. **Визуализация диффов** — изменения подсвечиваются прямо в файле,
   видно, что добавлено, а что удалено, можно выбирать отдельные строки
   для коммита (stage by line).

3. **Встроенный Merge Editor** — конфликты слияния решаются в удобном
   интерфейсе с кнопками «Accept Current / Incoming / Both», не нужно
   вручную править маркеры `<<<<<<<`.

## 1 вещь, удобнее в терминале

**Interactive rebase (`git rebase -i`)** — объединение, перестановка
и редактирование коммитов. В терминале это делается одной командой
и текстовым редактором, а в VS Code GUI такие операции скрыты
или неудобны.

# Мой пет-проект

**Идея:** Персональный сайт-визитка с портфолио учебных проектов.
Одностраничник с разделами «Обо мне», «Навыки», «Проекты», «Контакты».

**Стек:** HTML5, CSS3, JavaScript, Tailwind CSS, хостинг на GitHub Pages

**Цель:** научиться вёрстке адаптивных страниц, работе с CSS-фреймворками
и автоматическому деплою через GitHub Actions.
